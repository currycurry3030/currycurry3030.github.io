🎯 오늘의 목표

  • BPE/tokenizer가 training/inference 비용과 context 길이에 미치는 영향.
  • 핵심 용어 4개를 한국어로 설명한다.
  • 같은 문장을 서로 다른 tokenizer로 token 수 비교.

🧩 핵심 개념

BPE

빈번한 symbol pair를 반복 merge해 subword vocabulary를 만든다.

Vocabulary size

vocab이 크면 token 수가 줄 수 있지만 embedding/output matrix가 커진다.

Byte fallback

희귀 문자를 byte 단위로라도 표현해 OOV를 피한다.

Token fertility

같은 텍스트를 표현하는 데 필요한 token 수로 언어별 효율을 본다.

🧭 Mental Model

bytes/chars → initial symbols → pair counts → merge → token IDs

실무 연결: Recipe명·step·공정 약어·Metrology/FDC feature가 tokenizer에서 과도하게 분해되는지 확인하면 긴 Process Memory/RAG context의 실제 token budget을 추정할 수 있다.

주의: 영어 기준 tokenizer 효율이 한국어/도메인 텍스트에서도 같다고 가정하면 안 된다.
