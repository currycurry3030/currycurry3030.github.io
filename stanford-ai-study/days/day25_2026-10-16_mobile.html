🎯 오늘의 목표

  • STaR류 self-bootstrapping과 reasoning trace를 학습 데이터로 바꾸는 발상.
  • 핵심 용어 4개를 한국어로 설명한다.
  • 성공/실패 trace 저장 + good trace 선별 규칙 만들기.

🧩 핵심 개념

Self-bootstrapping

모델이 생성한 성공 reasoning/trajectory를 다시 학습 데이터로 사용한다.

Rationale/trace

정답에 도달한 중간 reasoning 또는 action trajectory다.

Filtering

correctness·quality·diversity·safety 기준으로 trace를 선별한다.

Curriculum

쉬운 성공에서 더 어려운 문제로 데이터 난이도를 확장한다.

🧭 Mental Model

sample tasks → generate traces → verify → filter → train → fresh eval

실무 연결: self-training 데이터는 모델이 스스로 만든 trace가 아니라, evidence가 명확하고 전문가 검토를 통과한 Evaluation Case/추천 trace를 우선 사용해야 한다.

주의: 정답만 맞은 나쁜 trace를 학습하면 shortcut과 오류를 강화할 수 있다.

🛠 20분 실습

  1. 전문가 승인 Evaluation Case/추천 trace만 학습 후보로 남기는 filtering rule 작성.
  2. 정상 동작 예시 1개를 만든다.
  3. 실패/edge case 1개를 만든다.
  4. 오늘 결과를 5줄로 요약한다.
