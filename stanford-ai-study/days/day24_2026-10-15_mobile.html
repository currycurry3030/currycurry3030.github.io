🎯 오늘의 목표

  • planner/executor 분리, adaptive decomposition, multi-step tool use.
  • 핵심 용어 4개를 한국어로 설명한다.
  • Planner → Executor → Observation → Re-plan 구조 추가.

🧩 핵심 개념

Planner

목표를 subgoal/dependency로 분해하고 다음 step을 정한다.

Executor

주어진 subtask를 실제 tool/model로 수행한다.

Adaptive decomposition

observation에 따라 plan의 step을 추가·삭제·재배열한다.

Structured state

완료 step·evidence·budget·미해결 질문을 명시적으로 저장한다.

🧭 Mental Model

goal → plan subtasks → execute one → observe → update state → re-plan → finish

실무 연결: Planner는 ‘무슨 recipe를 바꿀까’만 계획하지 않고 필요한 context 수집 → 과거 case 검색 → candidate 생성 → model prediction → constraint/uncertainty 검증 → engineer review 자료 생성 순서를 관리한다.

주의: 초기 계획을 너무 세밀하게 고정하면 실제 observation 변화에 취약해진다.

🛠 20분 실습

  1. Request → Context → Cases → Candidates → Predict → Constraint/OOD → Engineer Review 계획 구조 작성.
  2. 정상 동작 예시 1개를 만든다.
  3. 실패/edge case 1개를 만든다.
  4. 오늘 결과를 5줄로 요약한다.
