🎯 오늘의 목표

  • RMSNorm, RoPE, attention, MLP, residual stream. 현대 decoder LM 구조.
  • 핵심 용어 4개를 한국어로 설명한다.
  • 작은 Transformer block 구현/읽기.

🧩 핵심 개념

RMSNorm

activation의 RMS로 scale을 정규화하는 modern decoder의 흔한 norm이다.

RoPE

Q/K에 위치 의존 회전을 적용해 상대 위치 정보를 attention에 반영한다.

GQA/MQA

여러 query head가 더 적은 KV head를 공유해 KV cache 비용을 줄인다.

SwiGLU

gating이 들어간 MLP 변형으로 modern LLM에서 널리 쓰인다.

🧭 Mental Model

RMSNorm → attention+RoPE → residual → RMSNorm → SwiGLU → residual

실무 연결: 도메인 Agent 자체를 위해 LLM architecture를 새로 설계한다기보다, 사용하는 base/internal model의 context/KV 특성과 serving trade-off를 이해해 Context Builder 크기와 응답 SLA를 정한다.

주의: 각 구성요소를 이름만 외우지 말고 품질·메모리·속도 trade-off로 연결한다.
