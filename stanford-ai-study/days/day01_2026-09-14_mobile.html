🧩 핵심 개념

Q/K/V

Query는 찾는 정보, Key는 매칭 기준, Value는 실제 가져올 내용이다.

Scaled attention

softmax(QKᵀ/√dₖ)V로 관련 token 정보를 가중합한다.

Causal mask

미래 token을 보지 못하게 해 autoregressive 정보 누설을 막는다.

Residual + Norm

깊은 block에서 정보와 gradient 흐름, activation scale을 안정화한다.

🧭 Mental Model

token → embedding → Q/K/V → attention → residual+MLP

실무 연결: Attention 자체를 공정 의사결정 로직으로 해석하지는 않는다. 대신 긴 Evaluation Case·공정 문서·Recipe/Metrology context를 LLM이 처리하는 내부 메커니즘을 이해하는 기반으로 사용한다.

주의: Attention은 ‘단어 관계표’ 자체가 아니라 learned representation의 가중합이다.
