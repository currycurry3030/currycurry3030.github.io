🧩 핵심 개념

SFT

좋은 instruction-response 예시를 모방해 기본 assistant 행동을 만든다.

Preference data

같은 prompt의 chosen/rejected 응답 비교로 상대 선호를 제공한다.

RLHF

reward/preference signal을 이용해 policy를 강화학습으로 조정한다.

DPO

chosen likelihood를 상대적으로 올리고 rejected를 낮추는 preference objective다.

🧭 Mental Model

base → SFT → preference pairs → DPO or RLHF → aligned model

실무 연결: 구조화 Evaluation Case 생성 시 evidence를 꾸며내지 않기, provenance 필드 채우기, 모르면 abstain하기 같은 행동을 SFT/preference 관점으로 설계한다.

주의: alignment와 factual capability는 같은 축이 아니다.
