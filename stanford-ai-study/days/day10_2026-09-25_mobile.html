🧩 핵심 개념

Prefill

prompt 전체를 병렬 처리해 초기 hidden/KV를 만든다.

Decode

새 token 하나씩 순차 생성하며 과거 KV를 읽는다.

KV cache

과거 token의 Key/Value를 저장해 반복 projection 계산을 피한다.

Continuous batching

서로 다른 요청의 decode step을 동적으로 묶어 utilization을 높인다.

🧭 Mental Model

prompt → prefill → KV cache → decode token → append KV → repeat

실무 연결: 과거 Evaluation Case와 공정 context가 길어질수록 prefill/KV-cache 부담이 커진다. Context Builder의 pruning·summary·retrieval top-k가 serving 비용과 직결된다.

주의: prefill과 decode는 병목 특성이 다르므로 같은 방식으로 최적화하지 않는다.
