🧩 핵심 개념

Function calling

모델이 schema에 맞는 structured arguments를 생성해 tool을 호출한다.

Tool schema

name·description·input constraints·output contract를 정의한다.

MCP

AI application과 tools/resources를 표준 방식으로 연결하는 protocol이다.

Tool boundary

LLM은 의도와 arguments를 제안하고 deterministic layer가 검증·실행한다.

🧭 Mental Model

LLM chooses tool → validate args → authorize → execute → structured result → interpret

실무 연결: Tool layer는 get_process_context(), retrieve_cases(), predict_delta_metrics(), check_constraints(), rank_candidates()처럼 domain contract를 명확히 하고 DB 세부를 semantic layer 뒤에 숨긴다.

주의: 모델이 생성한 raw SQL/shell을 검증 없이 실행하지 않는다.
