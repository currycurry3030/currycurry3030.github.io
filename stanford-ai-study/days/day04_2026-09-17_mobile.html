🧩 핵심 개념

RAG

외부 문서를 검색해 context로 넣어 model weights 밖의 지식을 grounding한다.

Tool use

LLM이 structured call로 DB·함수·계산기 같은 외부 능력을 호출한다.

Agent loop

observation을 받아 다음 action을 반복 선택하는 control loop다.

Grounding

답의 주장과 외부 evidence를 연결해 검증 가능하게 만든다.

🧭 Mental Model

query → retrieve/tool → observation → reason/update → answer or next action

실무 연결: 실제 Agent의 RAG 대상은 과거 평가의 의도·조건·결과·해석·결론을 담은 Evaluation Case/Process Memory다. Tool은 공정 DB와 model/scorer를 연결한다.

주의: RAG 실패와 generation 실패를 분리해서 평가해야 한다.
