🎯 오늘의 목표

  • SFT와 RLHF를 model training 관점에서 재정리.
  • 핵심 용어 4개를 한국어로 설명한다.
  • SFT / DPO / RLHF 차이 1페이지.

🧩 핵심 개념

Instruction data

prompt-response demonstration을 정제·mix해 SFT data를 만든다.

Preference optimization

chosen/rejected나 reward로 응답 분포를 선호 방향으로 이동시킨다.

Reference/KL constraint

policy가 원래 모델에서 지나치게 멀어지는 것을 제한한다.

Eval gate

checkpoint를 capability·safety·format holdout으로 검증한다.

🧭 Mental Model

curate data → SFT → preference → DPO/RL → eval gate → deploy

실무 연결: Evaluation Case 생성용 LLM은 단순 범용 LLM 호출이 아니라 schema 준수·evidence 인용·hallucination 억제·abstention을 post-training/프롬프트/harness로 함께 만든다.

주의: training objective가 좋아져도 deployment metric이 자동으로 좋아지는 것은 아니다.
