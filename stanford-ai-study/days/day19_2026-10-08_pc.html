🧩 핵심 개념

Working memory

현재 task를 수행하는 동안 필요한 짧은 state/context다.

Episodic memory

과거 task/interaction의 구체적 경험을 저장한다.

Semantic memory

여러 경험에서 일반화된 사실·규칙·요약 지식이다.

Externalized memory

DB/vector store/file에 memory를 영속화하고 필요할 때 검색한다.

🧭 Mental Model

event → write policy → store+metadata → future query → retrieve → freshness check

실무 연결: Process Memory의 핵심 단위는 과거 평가의 의도·조건·recipe 변화·metrology 결과·해석·결론·evidence/provenance를 가진 구조화 Evaluation Case다.

주의: 모든 대화를 저장하면 noise·stale memory·privacy 문제가 누적된다.
