🎯 오늘의 목표

  • GPU memory hierarchy와 DP/TP/FSDP류 분산 방식의 목적을 이해.
  • 핵심 용어 4개를 한국어로 설명한다.
  • DP / TP / FSDP 차이를 한 장 그림으로 정리.

🧩 핵심 개념

Data Parallel

모델을 복제하고 batch를 나눠 처리한 뒤 gradient를 동기화한다.

Tensor Parallel

한 layer의 tensor 연산/parameter를 여러 GPU로 분할한다.

FSDP

parameter·gradient·optimizer state를 rank 사이 sharding한다.

Communication

all-reduce/all-gather 등 통신 비용이 scaling 효율을 제한한다.

🧭 Mental Model

model fit? → batch split → state sharding → layer split → communication overlap

실무 연결: 사내 model serving을 확장할 때 GPU parallelism을 이해하되, Recipe Advisor 품질 병목이 retrieval/query/validator 쪽인지 모델 inference 쪽인지 먼저 계측한다.

주의: GPU를 2배 늘려도 통신과 imbalance 때문에 throughput이 2배가 되지 않는다.
