🎯 오늘의 목표

  • Thought/Action/Observation을 번갈아 수행하는 agent loop와 failure handling.
  • 핵심 용어 4개를 한국어로 설명한다.
  • framework 없이 ReAct loop 구현.

🧩 핵심 개념

Reasoning state

다음 action을 고르기 위한 현재 plan·evidence·unresolved state다.

Action

schema가 정의된 tool call 또는 final answer다.

Observation

environment/tool이 반환한 실제 결과로 state를 갱신한다.

Stop condition

goal, max steps, budget, unrecoverable error 등 종료 규칙이다.

🧭 Mental Model

state → action → execute → observation → update → stop? → repeat

실무 연결: Agent loop는 요청 해석 → 관련 Evaluation Case 검색 → 필요한 공정 context 조회 → candidate Δrecipe 생성/예측 → constraint·OOD·uncertainty 검사 → 근거 포함 Top-k 반환으로 구성할 수 있다.

주의: ‘모델이 알아서 끝내겠지’에 의존하면 loop와 비용 폭주가 생긴다.

🛠 20분 실습

  1. retrieve_cases → context query → candidate generation → constraint check → final Top-k loop를 framework 없이 구현.
  2. 정상 동작 예시 1개를 만든다.
  3. 실패/edge case 1개를 만든다.
  4. 오늘 결과를 5줄로 요약한다.
