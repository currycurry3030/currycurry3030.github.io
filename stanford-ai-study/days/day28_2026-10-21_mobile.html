  • 핵심 용어 4개를 한국어로 설명한다.
  • Agent-Process Interface 명세 작성.

🧩 핵심 개념

Agent-Computer Interface

agent가 shell/file/editor/test 같은 computer 기능을 관찰·조작하는 인터페이스다.

Harness

agent loop·state·tools·retry·budget·logging을 감싸는 runtime이다.

Checkpoint/resume

중간 state/artifact를 저장해 긴 작업을 이어서 실행한다.

Tool ergonomics

agent가 이해하기 쉬운 action name·output·error를 설계하는 것이다.

🧭 Mental Model

task → harness state → agent action → ACI/tool → observation → checkpoint → repeat

실무 연결: Agent-Process Interface는 raw shell/DB 전체 대신 안전한 high-level domain tool을 제공한다. 예: retrieve_cases, get_process_context, predict_delta_metrics, check_constraints, rank_candidates.

주의: 모델 성능만 높여도 나쁜 interface와 harness 때문에 long-running task는 실패할 수 있다.
