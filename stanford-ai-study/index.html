학습 실습은 synthetic/비식별 예시만 사용. 실제 프로젝트 연결은 Process Memory + Recipe Advisor의 3-loop architecture로 일반화했습니다.
Loop 1 · Knowledge Capture

Evaluation Event → Context Builder → Knowledge Extraction Harness → Evaluation Case → Process Memory

Loop 2 · Recipe Decision

Current Context → Cases → Δrecipe Candidates → ΔMetric Prediction → Constraint/OOD/Uncertainty → Top-k → Engineer Review

Loop 3 · Learning / Improvement

Actual DOE Result → Prediction 비교 → New Evaluation Case → Process Memory/Eval → System Improvement
