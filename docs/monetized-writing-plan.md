# 수익화 가능한 자동 글쓰기 운영 계획

## 0. 전제 — 세션 이력에서 뽑은 사실

지난 한 달간 세션 203개를 분석한 결과, 이미 "글이 될 재료"가 매일 자동으로 생산되고 있음.

| 기존 자산 | 산출물 주기 | 글감 가치 |
|---|---|---|
| Stanford AI 30일 스터디 (CS224N/336/329Z/329A) | 9/23~11/2 매일 | 최상 — 36일치 연재 확정 |
| Hermes 에이전트 운영 (크론 8개, 스킬 153개) | 상시 | 상 — 실전 사례 희소 |
| 주식 스터디 (평일 5분 / 주말 Top-Down) | 주 6회 | 중 — 종목언급 리스크 |
| 부동산 트래커 (실거래·호가 파이프라인) | 상시 | 상 — 단 데이터 공개 범위 주의 |
| 개인 자산관리 (뱅샐→SQLite→주간리포트) | 주 1회 | 상 — 방법론만 공개 |
| 네이버 블로그 카드뉴스 파이프라인 | 매일 08:00 | 중 — 도구 소개용 |

즉 **새로 글감을 만들 필요가 없다.** 이미 돌고 있는 자동화의 부산물을 글로 변환하는 문제다.
이것이 요구사항 2번(나에게 유익)을 구조적으로 보장한다 — 내가 어차피 할 일의 정리물이기 때문.

## 1. 플랫폼 결정

자동 발행 가능성이 유일한 하드 제약이다.

| 플랫폼 | 자동 발행 | 수익 수단 | 판정 |
|---|---|---|---|
| GitHub Pages (현 `bjpark-lab.github.io`) | ✅ git push, 무료 | 애드센스(커스텀 도메인 필요) + 제휴 | **주력** |
| WordPress (self-host/워드프레스닷컴 비즈니스) | ✅ REST API | 애드센스 최적, 광고 자유 | 2단계 확장 |
| 티스토리 | ❌ Open API 2024-02 완전 종료 | 애드센스 | **제외** |
| 네이버 블로그 | ❌ 공식 쓰기 API 없음(브라우저 자동화는 약관 위반) | 애드포스트(단가 낮음) | 유입용 수동 미러링만 |

결론: **GitHub Pages를 주력 발행처로 하고, 네이버는 요약본 수동 미러링(주 1회, 5분)으로 한국어 검색 유입만 확보.**
티스토리는 자동화가 불가능하므로 검토 대상에서 완전히 뺀다.

### 수익화 경로 (순서대로)
1. **커스텀 도메인 취득** — `*.github.io` 서브도메인은 애드센스 사이트 소유권 확인에서 거절 사례가 많음. `.com`/`.dev` 도메인 연 1.5~2만원이 사실상 유일한 고정비.
2. **애드센스 승인 요건**: 독창적 장문 글 20~30편 + 개인정보처리방침/문의 페이지 + 3개월 정도의 발행 이력. 현재 6편 → 목표까지 약 12주.
3. **보조 수익**: 쿠팡파트너스(도서/장비), Amazon Associates(영문 글), 추후 유료 뉴스레터.

> 애드센스 정책 핵심: AI 사용 자체는 금지가 아니다. 금지 대상은 "사람의 가치 부여 없이 대량 생산된 콘텐츠"다.
> 따라서 아래 3번의 **검수 게이트가 정책 준수 장치이자 품질 장치**다.

## 2. 콘텐츠 라인업 (주 3편)

| 요일 | 시리즈 | 소스 | 분량 | 수익 기여 |
|---|---|---|---|---|
| 화 | **Stanford AI 학습노트** | `stanford-ai-study/` day N | 1,500~2,500자 | 검색 유입 주력, 36편 확보 |
| 목 | **에이전트 운영 실전** | Hermes 크론/스킬/실패 사례 | 2,000~3,000자 | 희소성 최상, 체류시간 ↑ |
| 토 | **데이터로 보는 것** | 부동산/자산/주식 파이프라인의 *방법론* | 2,000자+차트 | CPC 높은 금융 키워드 |

금지 규칙(레포 public-content-rule 확장):
- 실제 보유 종목·매수가·자산 금액·단지별 매수 의사 **절대 비공개**. 방법론과 익명화·합성 데이터만.
- 삼성전자 DS 관련 내부 정보(장비명, 레시피, lot ID, 사내 URL) 일절 금지.
- 메르 블로그 등 타인 콘텐츠는 인용 3줄 + 출처 링크까지만.

## 3. 운영 루프 — 검수 게이트가 중심

```
[월/수/금 07:00 크론]
  1. 소스 수집    : 해당 시리즈의 원재료 자동 수집
  2. 초안 생성    : 에이전트가 마크다운 초안 작성
  3. 자가 검증    : 링크 유효성 / 금칙어 스캔 / 표절 검사 / 분량
  4. 브랜치 push  : draft/2026-09-15-slug
  5. Telegram 보고 : 제목 + 3줄 요약 + 미리보기 URL + 승인 명령
        ↓
[주인님 검수]  승인 / 수정요청 / 폐기   ← 자동 발행 없음. 예외 없음.
        ↓
  6. 승인 시 main 머지 → GitHub Actions 빌드 → 공개
  7. 발행 후 7일째 성과(조회/유입 키워드)를 다음 주제 선정에 반영
```

검수 비용 목표: **편당 5분 이하.** 스마트폰에서 텔레그램 링크 열고 읽은 뒤 한 줄 회신으로 끝나야 한다.
그래서 초안은 반드시 "미리보기 URL"까지 만들어 보낸다. 마크다운 원문을 읽게 하지 않는다.

## 5. 현실적인 수익 기대치

거짓말하지 않고 적는다.

- 한국어 기술 블로그 애드센스는 월 1만 원 넘기기까지 보통 6~12개월.
- 주 3편 × 1년 = 약 150편, 월 방문 1만 정도면 월 3~10만 원 수준이 현실적 범위.
- **이 계획의 실제 수익은 광고비가 아니라**: ① 스탠포드 커리큘럼을 글로 쓰며 강제로 소화하는 학습 효과, ② 공개된 에이전트 운영 사례라는 커리어 자산, ③ 파이프라인 자체의 재사용 가치.
- 광고 수익만이 목적이라면 이 계획은 투자 대비 비효율이다. 이 점을 먼저 판단하셔야 한다.
